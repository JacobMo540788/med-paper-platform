# 不用每天开终端 — 浏览器直接打开网站

## 一次性配置（约 5–10 分钟）

1. 确保 **Docker Desktop** 已安装，并勾选 **开机自动启动**
2. 在资源管理器中进入项目的 `scripts` 文件夹
3. **双击** `首次配置-常驻运行.cmd`，按提示等待完成
4. （可选）**双击** `安装开机自启.cmd`，以后开机自动在后台运行

## 日常使用

| 设备 | 地址 |
|------|------|
| 本机电脑浏览器 | **http://localhost:3000** |
| 手机（同一 WiFi） | **http://电脑IP:3000** |

查看电脑 IP：Windows **设置 → 网络和 Internet → WLAN → 属性 → IPv4 地址**  
（你之前终端里出现过 `192.168.100.100`，手机可试 `http://192.168.100.100:3000`）

## 说明

- 配置完成后**不用**再运行 `npm run dev`，关掉终端也不影响网站（服务在后台）
- 每天 **07:00 北京时间** 仍会自动抓取新文献
- 停止后台服务：双击 `scripts\停止服务.cmd`
- 重新打开浏览器：双击 `scripts\打开网站.cmd`

## 手机打不开时

1. 手机和电脑连**同一个 WiFi**
2. Windows 防火墙可能拦截：首次访问时若弹出提示，选 **允许**
3. IP 地址变化后，用手机访问新的 `http://新IP:3000`

## 公网访问（不在家 WiFi 也能看）

需要把网站部署到云服务器（阿里云、腾讯云等），属于进阶操作，可另行配置。
